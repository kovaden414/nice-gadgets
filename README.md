Nice Gadgets
[DEMO LINK](https://kovaden414.github.io/nice-gadgets/)

Project Overview
Nice Gadgets is an online store interface for browsing and managing a selection of electronic gadgets. Users can explore products, add items to their favourites or shopping cart, and navigate through different sections of the site. The project demonstrates state management, responsive design, and interactive UI features in a modern React application.

Features
- Browse Products: View a catalog of gadgets with images and details.
- Favourites: Add or remove products from your favourites list.
- Shopping Cart: Add products to your cart and view the cart contents.
- Responsive Navigation: Adaptive header and menu for desktop and mobile.
- Smooth Scrolling: Click the logo to smoothly scroll to the top of the page.
- Dynamic Icons: Cart and favourites icons show item counts.

Technologies
- React
- TypeScript
- SCSS
- React Router

Installation
- Clone the repository:
git clone https://github.com/your-username/nice-gadgets.git
- Navigate to the project directory:
cd nice-gadgets
- Install the dependencies:
npm install
- Start the development server:
npm start
